# 终端模拟软件

基于 Python 的终端模拟软件，提供两种界面：

- **[gui.py](gui.py)（推荐，图形界面）**：带打开/关闭开关、消息收发、可视化日志，可与 MQTTX 互测
- [main.py](main.py)（命令行版）：自动运行两个功能，`python main.py write 0x0003 100` 可写入寄存器

实现功能：

1. **温湿度传感器模拟器**：传感器值存储于 JSON 文件，数值发生变化时通过 MQTT 及时上报
2. **Modbus TCP 数据采集**：通过 Modbus TCP 从从站采集寄存器数据并上报到 MQTT 服务器，支持向本小组寄存器写入值

## 环境依赖

```bash
pip install -r requirements.txt
```

依赖：`paho-mqtt`（MQTT 客户端）、`pymodbus`（Modbus TCP 客户端）。GUI 版使用 Python 自带的 tkinter，无需额外安装。

## 图形界面版（gui.py）

```bash
python gui.py
```

界面功能（自上而下）：

| 区域 | 功能 |
|---|---|
| **MQTT 连接** | 可修改服务器/端口/账号/密码；「打开连接」/「关闭连接」手动控制连接 |
| **功能控制** | 温湿度模拟「开始/停止」；Modbus 采集「开始/停止」；写入寄存器（地址+值+写入） |
| **消息收发** | 手动输入主题和内容「发送」；「订阅」任意主题（打开连接后自动订阅 `sensor_temphum,modbus/tcp/data`） |
| **消息日志** | 实时显示收发的消息（[系统]灰色 / [发送]蓝色 / [接收]绿色），可清空 |

**与 MQTTX 互测方法**：本程序发送的消息 MQTTX 订阅对应主题即可看到；MQTTX 发送消息到 `sensor_temphum` 或 `modbus/tcp/data`，本程序日志会实时显示 `[接收]`。程序自动过滤自己消息的回显，不会重复显示。

**MQTTX 远程控制**：向主题 `sensor_temphum` 发送指令，可远程控制温湿度模拟（数据与控制共用同一主题）：

| MQTTX 发送 | 终端模拟器动作 |
|---|---|
| `1` | 开始温湿度模拟（立即上报） |
| `0` | 停止温湿度模拟 |
| 其他内容（如 JSON 数据） | 作为普通消息显示在日志 `[接收]` |

## 配置说明

所有参数集中在 [main.py](main.py) 顶部的 **配置区**：

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `MQTT_BROKER` / `MQTT_PORT` | 172.16.4.211 / 9783 | MQTT 服务器地址与端口 |
| `MQTT_USER` / `MQTT_PWD` | test / 123456 | MQTT 账号密码 |
| `TOPIC_TEMP_HUM` | sensor_temphum | 温湿度上报主题 |
| `TOPIC_MODBUS` | modbus/tcp/data | Modbus 数据上报主题 |
| `JSON_FILE` | sensor_data.json | 温湿度 JSON 存储文件 |
| `MODBUS_IP` / `MODBUS_PORT` | 192.168.20.59 / 5502 | Modbus TCP 从站地址与端口 |
| `MODBUS_UNIT` | 1 | 从站地址（站号），必须显式指定（部分 pymodbus 版本默认站号不为 1） |
| `GROUP_ID` | 1 | **本小组编号**（修改为实际小组号） |
| `GROUP_REG_COUNT` | 5 | 每小组占用的寄存器个数 |

### 小组寄存器分配（避免小组间冲突）

从站寄存器总范围 `0x0000 ~ 0x0009`（10 个保持寄存器），按小组划分连续区间：

| 小组 | 寄存器区间 |
|---|---|
| 小组 1 | 0x0000 ~ 0x0004 |
| 小组 2 | 0x0005 ~ 0x0009 |

本程序只读写本小组对应的区间（`REG_START = 0x0000 + (GROUP_ID-1) * GROUP_REG_COUNT`），其他小组的寄存器不会被触碰。

## 运行方法

```bash
# 1. 同时运行两个功能（主循环，Ctrl+C 退出）
python main.py

# 2. 向本小组寄存器写入一个值（写后退出）
python main.py write 0x0003 100
```

## MQTT 消息格式（中文键，简洁易读）

### 温湿度（主题 sensor_temphum）

```json
{"设备": "小组1终端", "温度": 25.3, "湿度": 59.8, "时间": "12:40:07"}
```

### Modbus 数据（主题 modbus/tcp/data）

```json
{"设备": "小组1终端", "小组": 1, "寄存器": [155, 1, 200, 0, 0], "时间": "12:40:07"}
```

### 写入记录（主题 modbus/tcp/write）

```json
{"设备": "小组1终端", "寄存器地址": "0x0003", "值": 100, "时间": "12:40:07"}
```

> 使用 MQTTX 向本程序发送中文 JSON 同样有效，如 `{"温度": 22.5, "湿度": 55}`，日志会原样显示。

## 工作流程

```
┌─────────────────── 主循环(每2秒) ───────────────────┐
│                                                      │
│  功能1: 温湿度模拟器                                   │
│    读JSON → 模拟小幅波动 → 变化? → 写JSON + MQTT上报   │
│                                                      │
│  功能2: Modbus TCP采集                                │
│    读0x0000~0x0009(本小组区间) → MQTT上报             │
│                                                      │
└──────────────────────────────────────────────────────┘
```
