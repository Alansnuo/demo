# 终端模拟软件

基于 Python 的终端模拟软件，提供两种界面：

- **[gui.py](gui.py)（推荐，图形界面）**：打开/关闭连接开关、温湿度模拟、Modbus 采集与写入、消息收发、可视化日志
- [main.py](main.py)（命令行版）：自动循环运行温湿度模拟与 Modbus 采集

实现功能：

1. **温湿度传感器模拟器**：传感器值存储于 JSON 文件（保留最近 3 条记录），值发生变化时通过 MQTT 及时上报
2. **Modbus TCP 数据采集**：通过 Modbus TCP 从 PLC 从站采集寄存器数据并上报到 MQTT 服务器，每个小组只读写自己小组对应的寄存器，避免冲突

## 环境依赖

```bash
pip install -r requirements.txt
```

依赖：`paho-mqtt`（MQTT 客户端）、`pymodbus`（Modbus TCP 客户端）。GUI 使用 Python 自带 tkinter；Python 3.7 需额外安装 `typing_extensions`（requirements 已包含）。

## 主题一览

| 主题 | 方向 | 说明 |
|---|---|---|
| `sensor_temphum` | 上报 + 控制 | 温湿度数据上报；发 `1` 开启模拟、`0` 停止模拟 |
| `modbus/tcp/data` | 上报 | Modbus 寄存器采集数据 |
| `modbus/tcp/write` | 上报 | 寄存器写入记录 |

## 小组寄存器分配（避免小组间冲突）

从站 `192.168.20.59:5502` 共有 10 个保持寄存器（0x0000~0x0009），**每小组分配 1 个**，小组 N 对应寄存器 `0x0000 + (N-1)`：

| 小组 | 寄存器 | 小组 | 寄存器 |
|---|---|---|---|
| 小组 1 | 0x0000 | 小组 6 | **0x0005** |
| 小组 2 | 0x0001 | 小组 7 | 0x0006 |
| 小组 3 | 0x0002 | 小组 8 | 0x0007 |
| 小组 4 | 0x0003 | 小组 9 | 0x0008 |
| 小组 5 | 0x0004 | 小组 10 | 0x0009 |

当前配置为**小组 6**，只读写自己的 `0x0005`。修改 [gui.py](gui.py) / [main.py](main.py) 顶部的 `GROUP_ID` 即可切换小组（`GROUP_REG_COUNT` 可改每组寄存器个数）。

**防冲突机制**：程序只操作本小组区间；写入时校验地址，写其他小组的寄存器会被拒绝。

## 图形界面版（gui.py）

```bash
python gui.py
```

| 区域 | 功能 |
|---|---|
| 标题栏 | 显示小组编号、MQTT/Modbus 地址、寄存器区间（如 小组 6 · ... · 寄存器 0x0005~0x0005） |
| **① MQTT 连接设置** | 服务器/端口/账号/密码可编辑；「🔌 打开连接」/「🔌 关闭连接」手动控制 |
| **② 传感器模拟与 Modbus 采集** | 「🌡 开始模拟」温湿度模拟（变化才上报）；「📡 采集一次」手动读取一次寄存器并上报；「✍ 写入」写入本小组寄存器 |
| **③ 消息收发** | 手动输入主题和内容「📤 发送」；「📥 订阅」任意主题（自动订阅 `sensor_temphum,modbus/tcp/data`） |
| **④ 消息日志** | 实时显示收发消息（[系统]灰 / [发送]蓝 / [接收]绿），自动过滤自身消息回显 |

### 操作流程

1. 点「🔌 打开连接」
2. 点「🌡 开始模拟」→ 温湿度上报到 `sensor_temphum`
3. 点「📡 采集一次」→ 读取 `0x0005` 并上报到 `modbus/tcp/data`
4. 写入测试：地址填 `0x0005`，值填数字，点「✍ 写入」

### MQTTX 远程控制

向 `sensor_temphum` 发送：

| MQTTX 发送 | 终端模拟器动作 |
|---|---|
| `1` | 开始温湿度模拟（立即上报） |
| `0` | 停止温湿度模拟 |
| 其他内容（如 JSON 数据） | 作为普通消息显示在日志 `[接收]` |

## MQTT 消息格式（中文键，简洁易读）

### 温湿度（主题 sensor_temphum）

```json
{"温度": 25.3, "湿度": 59.8, "时间": "14:04:44"}
```

### Modbus 数据（主题 modbus/tcp/data）

```json
{"寄存器": [7218], "时间": "14:04:44"}
```

### 写入记录（主题 modbus/tcp/write）

```json
{"寄存器地址": "0x0005", "值": 100, "时间": "14:04:44"}
```

## JSON 存储格式（保留最近 3 条）

[sensor_data.json](sensor_data.json) 保存温湿度最近 3 条记录，最新在前：

```json
{
  "records": [
    {"温度": 15.0, "湿度": 59.5, "时间": "14:27:48"},
    {"温度": 15.2, "湿度": 58.5, "时间": "14:27:46"},
    {"温度": 14.8, "湿度": 58.3, "时间": "14:27:44"}
  ]
}
```

程序启动时读取最新一条作为模拟起点；旧格式（单值）文件会自动转换。

## 命令行版（main.py）

```bash
# 同时运行两个功能（主循环，Ctrl+C 退出）
python main.py

# 向本小组寄存器写入一个值（写后退出）
python main.py write 0x0005 100
```
